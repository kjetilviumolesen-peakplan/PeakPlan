# PeakPlan Alpha 0.1

A lightweight starter for PeakPlan: a calm training coach for busy people.

## What is included
- Flutter app scaffold
- Basic home screen
- Availability editor
- Goals editor
- Simple weekly plan engine
- FastAPI backend starter

## Suggested repo layout

```text
PeakPlan/
├── app/
│   ├── pubspec.yaml
│   └── lib/
│       ├── main.dart
│       ├── models/
│       ├── screens/
│       └── services/
├── backend/
│   ├── main.py
│   └── requirements.txt
└── README.md
```

## Next step

1. Create a Flutter project inside `app/` or copy these files into an existing Flutter app.
2. Run the backend with FastAPI.
3. Replace the placeholder plan engine with your real logic.
